# Sway Window Manager Architecture & Reference

Architectural standards, window rules, workspace layout, and modular keybindings for Sway (Wayland) on CachyOS.  
Use this document as the single source of truth for window management and display orchestration.

---

## 1. Modular Configuration Architecture (`~/.config/sway/config.d/`)

To ensure token efficiency for AI agents and maintainability for developers, the monolithic 680+ line configuration is structured into logical subcategory files:

| File | Purpose | Lines / Scope |
| :--- | :--- | :--- |
| `00-variables.conf` | Modifiers (`$mod = Mod4`), workspace definitions (`$ws1`–`$ws10`), font, defaults. | Variable declarations |
| `10-display.conf` | `eDP-1` display output mode, 165Hz refresh, cursor theme/size, border styles, theme colors, `apply-vibrance` reload hook. | Display pipeline |
| `20-input.conf` | Keyboard repeat rates, touchpad natural scroll, pointer accel, 3-finger/4-finger gestures. | Input devices |
| `30-window-rules.conf` | Floating utilities (`bluetui`, `wifui`, `rofi-network`, `me3-manager`, `ds3-randomizer`, `cycles-installer`), Thunar rules, Brave tabbed view, Steam shell focus management, Workspace 4 gaming rules. | Window assignments |
| `40-keybindings.conf` | Window navigation, workspace switching, scratchpad toggles, launchers (`rofi-network` on `$mod+Mod1+5`, `bluetui` on `$mod+Mod1+2`), cursor theme/size hotkeys. Marks system removed 2026-10-18. | Key chords |
| `50-gaming-mode.conf` | Passthrough gaming mode (`mode "gaming"` via `Alt + Shift + F`), muted shortcuts, game hotkeys. | Gaming isolation |
| `60-autostart.conf` | D-Bus/systemd session imports, daemons (`mako`, `polkit`), night light, wallpaper, game-workspace-daemon. | Session bootstrap |
| `70-bar.conf` | Native `swaybar` inclusion and dock/hide state restore. | Status bar |
| `80-theme-colors.conf` | GENERATED by `theme-set` (do not edit). Client border colors persisted so fresh sway starts keep the theme: focused border = accent, unfocused/inactive border = `bg2` (dim but visible). Regenerated on every `theme-set`. | Theme border persistence |

The root entrypoint (`~/.config/sway/config`) contains:
```ini
include ~/.config/sway/config.d/*.conf
```

## 2. Hardware & Display Pipeline

* **Display Output:** ASUS TUF Gaming F16 built-in display (`eDP-1`).
  * Resolution: `1920x1200` (16:10 aspect ratio).
  * Refresh Rate: `165.000Hz`.
  * Position: `0 0`.
  * Adaptive Sync: `off` (prevents panel backlight flickering/gamma shifts on 165Hz laptop panels).
  * Allow Tearing: `yes` (reduces frame delivery latency in fullscreen gaming).
* **GPU Strategy:**
  * Machine supports dynamic GPU architectures via `supergfxctl` (`Integrated`, `Hybrid`, and `AsusMuxDgpu`).
  * Direct dGPU MUX connects RTX 5050 Mobile directly to eDP-1 with hardware vibrance via `nvibrant`.

## 4. Window Navigation & Scratchpad Architecture

* **Vim-Style Focus:** `Win + h` (Left), `Win + j` (Down), `Win + k` (Up), `Win + l` (Right).
* **Move Windows:** `Win + Shift + h/j/k/l`.
* **Splits:** `Win + b` (Horizontal split), `Win + Shift + b` (Split toggle).
* **Fullscreen:** `Win + f` (Toggle fullscreen).
* **Floating / Tiling Toggle:** `Alt + Shift + Space` (toggles the floating STATE of the focused window).
* **Focus Layer Toggle:** `Shift + Space` (swaps focus between the foreground floating window and the background tiled/tabbed layer underneath, via toggle-floating-focus).
* **Window Graceful Close:** `Win + q` (polite WM_DELETE close).
* **Window Force Kill:** `Win + BackSpace` (SIGKILL via `force-kill-window`).

### Scratchpads (`~/.local/bin/scratch-toggle`)
Canonical dimensions: `1700x1050`, centered on display. Windows are **lazy-loaded on demand** on initial hotkey press to eliminate idle RAM waste:
1. **Terminal Scratchpad:** `Alt + \`` or `Ctrl + Space` (Guarded: `SCRATCH_GAME_GUARD=1` silent no-op when game focused).
2. **Notes Scratchpad:** `Win + n` (Spawns/toggles Neovim on `~/notes.md`).
3. **Spotify Scratchpad:** `Win + m` (Spawns/toggles Spotify window).
4. **Video Player (mpv):** `Win + -` or `Win + _` (1280x720 floating scratchpad).

### Cursor Controls (`toggle-cursor-theme` & `adjust-cursor-size`)
* **Theme Polarity Toggle:** `Alt + Shift + c` (Toggles between `phinger-cursors-gruvbox-material` and `phinger-cursors-gruvbox-material-light`).
* **Size Adjustment (+2 / -2):**
  * `Alt + Shift + =` (or `Alt + +`): `+2px`
  * `Alt + Shift + -` (or `Alt + -`): `-2px`
  * Updates GSettings, GTK 2/3/4, Xresources, and `seat seat0 xcursor_theme` in `10-display.conf`.

## 5. Gaming Rules & Isolation (Workspace 4)

All game processes and launchers are strictly confined to **Workspace 4**:
* Classes: `^steam_app_.*$`, `cs2`, `gamescope`, `eldenring`, `steam_proton`, `gtaiv`, `dyinglight`.
* Flags applied: `fullscreen enable`, `allow_tearing yes`, `shortcuts_inhibitor enable`, `inhibit_idle focus`.
* Game Launchers: Rockstar, Social Club, etc., move to Workspace 4 and float centered without stealing input focus (`no_focus`).
* **Gaming Mode (`Alt + Shift + F`):** Mutes all desktop hotkeys, passing input directly to the game. Only workspace switching and emergency OBS/screenshot shortcuts remain active. Switching away from ws4 automatically returns to default desktop mode.

## 6. Pre-Completion Validation & Verification

Before modifying or reloading Sway configurations:
1. Validate syntax: `sway -C`
2. Audit keybindings for duplicate/shadowed chords: `sway-mcp` (`sway_validate_config`)
3. Reload configuration: `swaymsg reload`

## 7. System Diagnostics & Architectural Audit (`sway-diagnostics`)

A dedicated, non-invasive system diagnostics auditor is installed at `~/.local/bin/sway-diagnostics` (managed in chezmoi).

### Execution
```bash
sway-diagnostics          # Standard formatted table with ANSI status highlighting
sway-diagnostics -q       # Quiet exit-code mode (0 = healthy, 1 = required component failed)
sway-diagnostics --json   # Machine-readable JSON output for integrations
```

### Architectural Classification
* **REQUIRED CORE:** Sway Compositor (`swaymsg`, syntax validation), Wayland Socket integrity, and `xremap` key remapper.
* **DISPLAY & GPU:** `supergfxctl` mode, NVIDIA driver health/temperature/wattage, focused output mode/165Hz/tearing/scale filter, and hardware vibrance backend (`nvibrant` / `ctm-test`).
* **RESIDENT SERVICES:** Persistent infrastructure only: PipeWire, WirePlumber, XDG Portals (`portal` + `wlr`), `mako`, and `cliphist` (with live `wl-paste` watcher verification).
* **OPTIONAL DESKTOP LAYERS:** Terminal (Alacritty), File Manager (Thunar), Visualizer (Cava), Theme Engine (`theme-set`), and active wallpaper.
* **GAMING STACK:** CS2 launcher, Legendary, Proton runtimes, process niceness scheduler (`ananicy-cpp` vs `gamemoded` isolation), and protected MangoHud configuration.
* **HEALTH & STORAGE:** Failed system/user systemd units count and Btrfs root filesystem capacity/metadata status.

## 8. Idle Management, Screen Locking & Hardware Wakeup

Idle sequencing is managed by `swayidle` in [`~/.config/sway/config.d/60-autostart.conf`](file:///home/onyx/.config/sway/config.d/60-autostart.conf):
* **300s (5m):** Session locked via `swaylock -f -c 000000`.
* **600s (10m):** Output display DPMS disabled (`output * dpms off`).
* **Deep Idle / Suspend:** Hardware low-power sleep (`s2idle`) managed by systemd.

For full architectural breakdown of why only the USB mouse wakes the machine from `s2idle` while the internal keyboard and Bluetooth keyboard remain dormant, refer to [`swayidle-locking-wakeup.md`](file:///home/onyx/docs/system/swayidle-locking-wakeup.md).
